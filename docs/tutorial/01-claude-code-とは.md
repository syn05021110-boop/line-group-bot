# 01. Claude Code とは何か？

## ひとことで言うと

**「コードに対して指示を出すと、ファイルを読み・直し・テストまで実行してくれる AI アシスタント」** です。

ChatGPT が「文章で答えてくれる AI」だとすると、Claude Code は **「あなたのパソコンの中で実際に作業してくれる AI」** です。

## ChatGPT・Claude（チャット版）との違い

| | ChatGPT / Claude（チャット版） | **Claude Code** |
|--|--|--|
| 動く場所 | ブラウザ | **あなたのパソコンのターミナル** |
| ファイルを読める？ | コピペすれば読める | **自動で読みに行く** |
| ファイルを書き換えられる？ | コードを返すだけ。自分で貼り付ける必要あり | **直接ファイルを編集する** |
| コマンド実行できる？ | できない | **`npm install` や `git` を実行できる** |
| 複数ファイルにまたがる作業 | 苦手 | **得意（プロジェクト全体を理解する）** |

つまり、**「コードをコピペで往復させる手間」が消える** のが最大の特徴です。

## 具体的に何ができる？

このリポジトリ（`line-group-bot`）を例にすると、こんなことが指示一つで実現できます。

- 「`server.mjs` が何をやっているか日本語で説明して」
- 「`.env.example` をコピーして `.env` を作って」
- 「`README.md` を書いて」
- 「Bot の返信が遅い。原因を調べて修正して」
- 「テストを書いて、実際に動くか確認して」

## どうやって動いている？

ざっくり言うと、こういう仕組みです。

```
あなた（日本語で指示）
   ↓
Claude Code（CLI ツール）
   ↓
Claude というAI が「何をすべきか」を判断
   ↓
ファイルを読む / 書く / コマンドを実行する
   ↓
結果をあなたに報告
```

「危ないコマンド（ファイルを消す等）」を実行する前は、必ずあなたに確認します。**勝手に破壊することはありません**。

## どこで使える？

| 場所 | 説明 |
|------|------|
| **ターミナル（CLI）** | 一番基本。このチュートリアルではこれを使います |
| デスクトップアプリ（Mac/Windows） | GUI 版。同じことができます |
| Web 版（claude.ai/code） | ブラウザから使える版 |
| VS Code 拡張 | エディタの中から呼び出せる |
| JetBrains 拡張 | 同上 |

まずは **ターミナル版** に慣れましょう。慣れれば他の環境にも応用できます。

## 料金について

- Claude Code 自体は無料で使えます
- ただし、内部で Claude API を呼ぶので **API 利用料** がかかります
- または **Claude Pro / Max プラン** のサブスクリプションで使い放題にできます
- 個人で勉強する分には Pro プラン（月 20 ドル程度）が分かりやすいです
