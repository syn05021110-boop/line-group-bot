# Claude Code はじめてのチュートリアル

このチュートリアルは **プログラミング未経験の方** が、AI コーディングアシスタント **Claude Code** を使えるようになることを目的としています。

題材としてこのリポジトリ（`line-group-bot`）を使いますが、コードを書けるようになる必要はありません。**Claude Code に「お願いする」だけ** で、コードを読んだり修正したりできるようになるのがゴールです。

## 想定読者

- プログラミングはほぼ未経験
- ターミナル（黒い画面）を触ったことがない、または少ししかない
- ChatGPT や Claude（チャット版）は使ったことがある程度
- 「コードを読まずに、AI に丸ごとお願いしたい」と思っている

## 進め方のコツ

- **一気に全部読まない**。1日1〜2章ずつで OK
- **必ず手を動かす**。読むだけだと身につきません
