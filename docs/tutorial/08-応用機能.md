## 1. フック（Hooks）

**フック** は「特定のタイミングで自動で実行するコマンド」を仕込む仕組みです。

例：
- **コード変更後に必ず lint を実行する**
- **コミット前に test を走らせる**
- **Claude Code が終了したときに音を鳴らす**

### 設定する場所

`~/.claude/settings.json`（あなたのパソコン全体）または `.claude/settings.json`（このプロジェクトだけ）に書きます。

例（コード保存後に lint を実行する設定）：

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit",
        "hooks": [
          {
            "type": "command",
            "command": "npm run lint"
          }
        ]
      }
    ]
  }
}
```

### よくあるイベント

| イベント | 発生タイミング |
|----------|----------------|
| `PreToolUse` | ツール実行の **直前** |
| `PostToolUse` | ツール実行の **直後** |
| `SessionStart` | Claude Code 起動時 |
| `Stop` | 会話が一段落した時 |

> 💡 「コミット前に必ずテスト」のような **自動化** をやりたいときに使います。詳しくは Claude Code に「フックの設定方法を教えて」と聞いてみてください。

## 2. MCP（Model Context Protocol）サーバー

**MCP** は「Claude Code に外部ツールを繋ぐ規格」です。

たとえば：
- **GitHub MCP**：GitHub の Issue / PR を直接操作
- **Slack MCP**：Slack にメッセージを送る
- **Notion MCP**：Notion のページを読み書きする
- **Filesystem MCP**：別フォルダのファイルにアクセス

### 設定する

```
/mcp
```

で MCP サーバーの管理画面に入れます。`add` を選んで、サーバーの URL や認証情報を入れます。

### 使い方の例

GitHub MCP を入れたら：

```
syn05021110-boop/line-group-bot の最新の Issue を一覧で見せて
```

→ Claude Code が GitHub MCP 経由で API を叩いて返してくれます。

> 💡 このリポジトリでは **GitHub MCP がすでに使えるようになっています**（Web 環境）。

## 3. IDE 連携

VS Code や JetBrains を使う場合、**拡張機能** を入れると Claude Code がエディタの中で使えます。

### VS Code の場合

1. 拡張機能で「Claude Code」を検索してインストール
2. コマンドパレット（`Cmd + Shift + P`）で `Claude: Start` を実行
3. サイドバーから Claude Code を呼び出せる

エディタで選択したコードを **そのまま Claude Code に渡せる** ので、CLI より楽な場面も多いです。

## 4. Claude Agent SDK

ここからは **プログラマー向け**。「Claude Code みたいな AI エージェントを自分のアプリに組み込みたい」場合の話です。

`@anthropic-ai/claude-agent-sdk` というライブラリを使えば、Claude Code と同じエンジンで動く独自のエージェントを作れます。

例：このリポジトリの Bot も、**もっと頭良くしたければ Claude Agent SDK でリプレース** することも可能です。

## 5. 設定ファイル `settings.json`

Claude Code の挙動は `settings.json` で細かく調整できます。

| 場所 | 効果範囲 |
|------|----------|
| `~/.claude/settings.json` | 全プロジェクト共通（あなたのパソコン） |
| `.claude/settings.json` | このプロジェクトだけ（git で共有） |
| `.claude/settings.local.json` | このプロジェクトだけ（git で共有しない） |

### 例：よく使う設定

```json
{
  "model": "claude-sonnet-4-6",
  "permissions": {
    "allow": [
      "Bash(npm test)",
      "Bash(npm run lint)"
    ]
  },
  "env": {
    "CUSTOM_VAR": "value"
  }
}
```

`permissions.allow` に書いたコマンドは **確認なしで実行** されるので、よく使う安全なコマンドを並べると体験が滑らかになります。

## 6. キーバインド

Claude Code 内のキーボードショートカットも変えられます。

`~/.claude/keybindings.json` にカスタム設定を書けます。

詳しくは Claude Code に「キーバインドのカスタマイズ方法を教えて」と聞けば、`/keybindings-help` 系のヘルプが出ます。

---

## 7. その他のヒント

### 並行セッション

複数のターミナルで `claude` を同時起動して、**別々の作業を並行で進める** ことができます。

### ファイル添付（@）

`@` を打つとファイル候補が出るので、長いパスを覚えなくて済みます。

### `--` 系オプション

```bash
claude --help
```

で起動時オプションが全部見れます。`--continue`、`--resume`、`--model` などが特によく使われます。
