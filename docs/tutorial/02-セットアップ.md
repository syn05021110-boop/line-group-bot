# 02. セットアップ

Claude Code を動かすために、3つのものを用意します。

1. **ターミナル**（あなたのパソコンに最初から入っています）
2. **Node.js**（Claude Code を動かす土台）
3. **Claude Code 本体**

順番にやっていきましょう。

---

## 用語の予備知識

知らなくても進めますが、知っていると安心です。

| 用語 | 意味 |
|------|------|
| ターミナル | 「黒い画面」のこと。文字でパソコンに命令する場所 |
| コマンド | ターミナルに打ち込む命令（例: `ls`） |
| Node.js | JavaScript というプログラミング言語をパソコンで動かす仕組み |
| npm | Node.js 用のアプリ管理ツール |

---

## ステップ1: ターミナルを開く

### Mac の場合
1. `Command + Space` で Spotlight を開く
2. `ターミナル` と入力して Enter

### Windows の場合
1. スタートメニューを開く
2. `PowerShell` または `Windows Terminal` と入力して Enter

開くとこんな画面になります（色は環境で違います）。

```
yourname@MacBook ~ %
```

この `%` や `$` の右側にコマンドを打ち込みます。

### お試しコマンド

まず慣れるために、以下を打ってみましょう。

```bash
pwd
```

Enter を押すと、「今いる場所（フォルダのパス）」が表示されます。

```bash
ls
```

「今いる場所にあるファイル一覧」が表示されます。

これだけ覚えれば OK です。

---

## ステップ2: Node.js をインストール

Claude Code は Node.js の上で動くので、まず Node.js を入れます。

### おすすめ：公式インストーラー

1. ブラウザで [https://nodejs.org](https://nodejs.org) を開く
2. **LTS 版**（左側のボタン）をダウンロード
3. ダウンロードしたファイルを開いてインストール（基本的に「次へ」を連打で OK）

### インストールできたか確認

ターミナルで以下を実行：

```bash
node --version
```

`v20.10.0` のような数字が出ればOK。**v18 以上** が必要です。

```bash
npm --version
```

これも数字が出れば OK。

> もし `command not found` と出る場合は、一度ターミナルを閉じて開き直してみてください。

---

## ステップ3: Claude Code をインストール

ターミナルで以下を実行：

```bash
npm install -g @anthropic-ai/claude-code
```

> `-g` は「グローバルに（パソコン全体で使えるように）」という意味です。

インストールが終わったら確認：

```bash
claude --version
```

バージョンが表示されれば成功です。

---

## ステップ4: Claude Code にログイン

```bash
claude
```

と打って Enter。初回はログインが求められます。

- 画面に表示される URL をブラウザで開く
- Anthropic アカウントでログイン（持ってなければ作成）
- 表示されたコードをターミナルに貼り付け

これでログイン完了です。

> **どのプラン？**：「Claude Pro」「Claude Max」「API キー」のどれを使うか選べます。よくわからなければ、佐藤さんに聞いてください。

---

## ステップ5: プロジェクトに移動

このチュートリアルでは `line-group-bot` を題材にします。リポジトリのフォルダに移動しましょう。

```bash
cd ~/line-group-bot
```

> `cd` は「Change Directory（フォルダ移動）」の略です。
> `~` は「ホームフォルダ」を意味します。

場所が合っているか確認：

```bash
pwd
```

`/Users/yourname/line-group-bot` のように、末尾が `line-group-bot` になっていれば OK。

```bash
ls
```

`CLAUDE.md`、`server.mjs`、`package.json` などが見えればバッチリです。

---

## ステップ6: Claude Code を起動

いよいよ起動です。

```bash
claude
```

`>` のようなプロンプトが出たら成功！ ここに日本語で指示を打ち込みます。

終了したい時は、以下のいずれかで抜けられます。

- `Ctrl + C` を2回押す
- `/exit` と打って Enter

---

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| `npm install -g` で permission エラー | 先頭に `sudo` をつけて再実行（Mac/Linux）|
| `command not found: claude` | ターミナルを開き直す。それでもダメなら Node.js を再インストール |
| ログイン画面が開かない | ターミナルに表示された URL を手動でブラウザにコピペ |
