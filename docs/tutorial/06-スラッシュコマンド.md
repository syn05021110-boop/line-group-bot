# 06. スラッシュコマンド

`/` から始まるコマンドを **スラッシュコマンド** と呼びます。
よく使う機能をワンタッチで呼び出せる便利な仕組みです。

---

## 起動して試してみよう

Claude Code を起動した状態で：

```
/
```

と打つだけで、使えるコマンド一覧が表示されます。**矢印キーで選んで Enter** で実行できます。

---

## 覚えておきたい基本コマンド

| コマンド | 用途 |
|----------|------|
| `/help` | ヘルプを表示 |
| `/clear` | 会話をリセット（記憶を消す） |
| `/exit` | Claude Code を終了 |
| `/init` | プロジェクトを調査して CLAUDE.md を生成 |
| `/config` | 設定変更（テーマ、モデルなど） |
| `/model` | 使用するモデル（Opus / Sonnet / Haiku）を切り替え |
| `/cost` | これまで使った API コストを表示 |
| `/login` / `/logout` | アカウント切り替え |

---

## 開発で役立つコマンド

| コマンド | 用途 |
|----------|------|
| `/review` | プルリクエスト（PR）をレビューする |
| `/security-review` | 現在の変更にセキュリティ問題がないかチェック |
| `/agents` | サブエージェント（補助 AI）の管理 |
| `/mcp` | MCP サーバー（外部ツール連携）の管理 |
| `/permissions` | このプロジェクトで許可するコマンドを設定 |

---

## 演習1: /help を試す

Claude Code 内で：

```
/help
```

ヘルプが表示されます。コマンド一覧の早見表として便利です。

---

## 演習2: /cost で料金を確認

```
/cost
```

ここまでにいくら使ったかが分かります。**勉強中はちょこちょこ見て、感覚を掴むのがおすすめ** です。

---

## 演習3: /clear で会話を切る

長く話していると、会話の文脈が膨らんで Claude Code が混乱することがあります。**話題が変わるタイミングで `/clear`** すると、頭がスッキリした状態で続けられます。

```
/clear
```

> 💡 重要：`/clear` すると **それまでの会話は完全に消えます**。続きから再開したい時は使わず、`claude -c` で復帰する方が安全です。

---

## 演習4: /model でモデル切り替え

Claude には複数のモデルがあります（**料金 vs 賢さ** のバランスが違います）。

| モデル | 特徴 |
|--------|------|
| **Opus** | 最も賢いが料金が高い。難しい設計や複雑なバグ調査向け |
| **Sonnet** | バランス型。普段使いはこれで十分なことが多い |
| **Haiku** | 軽量・高速・安価。簡単な質問やテキスト整形向け |

```
/model
```

メニューから選べます。

## カスタムスラッシュコマンドを作る

自分でスラッシュコマンドを **新規に作る** こともできます。

例：「テストとビルドを連続実行する」コマンドを作る

1. ファイルを作る：`.claude/commands/test-and-build.md`
2. 中に「やってほしいこと」を書く：

```markdown
npm run lint を実行し、エラーがあれば修正してください。
その後 npm test を実行し、すべてのテストが通ることを確認してください。
最後に npm run build を実行してください。
```

3. これで `/test-and-build` というコマンドが使えるようになります。

> 💡 **応用**：チームで使うコマンドは `.claude/commands/` に置いて git にコミット。個人用は `~/.claude/commands/` に置きます。

---

## 演習5: 簡単なカスタムコマンドを作る

「このプロジェクトを起動するために必要な準備をすべて確認する」コマンドを作ってみましょう。

Claude Code に：

```
.claude/commands/setup-check.md というファイルを作って。
中身は、
- node のバージョンが18以上か
- .env が存在するか
- credentials/tokens.json が存在するか
- npm install 済みか（node_modules があるか）
をチェックする内容にして
```

作成後、Claude Code を再起動して `/setup-check` と打てば実行できます。

---

## @ファイル参照

スラッシュコマンドではないですが、似た便利機能として **`@`** があります。

```
@server.mjs の handleEvent を直して
```

`@` を打つと **ファイル名の候補が出てきます**。Tab で補完できるので、長いパスを打たなくて済みます。
