# 05. CLAUDE.md 活用

この章では、Claude Code の **賢さを引き出す秘密のファイル** について学びます。

それが **`CLAUDE.md`** です。

---

## CLAUDE.md とは

プロジェクトのフォルダに置く **「Claude Code への取扱説明書」** です。

Claude Code は起動時に自動でこのファイルを読みます。つまり、毎回「このプロジェクトはこういうものです」と説明しなくても、最初から理解してくれるようになります。

このリポジトリにも既にあります：

```bash
cat CLAUDE.md
```

中身を見ると：

- プロジェクト概要
- フォルダ構成
- 動作の仕組み
- 環境変数の説明
- よくあるエラー対応

…が書かれています。**これがあるから、Claude Code はあなたが何もしなくても、line-group-bot を理解できる** わけです。

---

## なぜ CLAUDE.md が大事？

たとえば、CLAUDE.md がない場合：

```
> .env を作って
```

→ Claude Code「どんな環境変数が必要ですか？」と聞き返してくる

CLAUDE.md があれば：

```
> .env を作って
```

→ Claude Code「`.env.example` を見て、必要な環境変数を全部入れた `.env` を作りました」

このように **「分かってる前提」で動いてくれる** のが大きな違いです。

---

## CLAUDE.md に書くべきこと

| 項目 | 例 |
|------|-----|
| プロジェクトの目的 | 「LINE グループで質問に自動回答する Bot」 |
| 使うコマンド | `npm start`, `npm run dev` |
| フォルダ構成 | server.mjs はメイン、lib/ はライブラリ… |
| ルール・規約 | 「コメントは日本語で」「テストは vitest を使う」 |
| 注意点 | 「本番環境では .env.production を使う」 |

---

## 演習1: CLAUDE.md を改善してもらう

実は CLAUDE.md 自体も Claude Code に改善してもらえます。

```
CLAUDE.md を見て、初心者が読んでも分かりやすいか確認して。
分かりにくい部分があれば修正案を出して
```

提案を見て、よければ採用、違えば「ここはこう変えて」と指示します。

---

## 演習2: 新しいルールを追加する

たとえば、自分用に「日本語で説明してほしい」「コメントは絵文字を使わない」などのルールを CLAUDE.md に書き加えると、以降ずっと守ってくれます。

```
CLAUDE.md の最後に「コミュニケーションルール」セクションを追加して、
以下の3つを書いて：
- コードコメントは日本語で書く
- 専門用語が出たら必ず日本語で説明する
- ファイルを変更する前に必ず計画を提示する
```

---

## CLAUDE.md は階層構造にできる

- **ユーザー全体**：`~/.claude/CLAUDE.md`（あなたのパソコン全体）
- **プロジェクト**：`./CLAUDE.md`（このリポジトリ）
- **サブフォルダ**：`./lib/CLAUDE.md`（lib フォルダ内だけのルール）

下のほうが優先されます。「このフォルダだけ別ルール」も書けます。

---

## メモリ機能（#で記憶）

会話中に **`#` から始まる行** を書くと、その内容を CLAUDE.md に追記するか聞いてくれます。

```
# このプロジェクトでは、ログは日本語で出力する
```

これで「次回からも覚えておいてね」と Claude Code に指示できます。便利です。

---

## /init コマンド

新しいプロジェクトで CLAUDE.md がまだ無い場合、

```
/init
```

と打つと、Claude Code が **プロジェクトを調査して CLAUDE.md を自動生成** してくれます。

> 💡 まずは `/init` で叩き台を作って、後から手で整えるのがおすすめです。

---

## やってはいけないこと

- **秘密情報を書かない**：API キーやパスワードは絶対に CLAUDE.md に書かないでください。git で共有されるとバレます
- **長すぎる文章を書かない**：要点だけ。冗長だと Claude Code もあなたも疲れます
- **頻繁に変えすぎない**：基本ルールは固定が安全。指示ごとの細かい要望は会話の中で伝えましょう
