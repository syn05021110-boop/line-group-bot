# 07. 便利な機能

ここからは Claude Code の **「これ知ってると劇的に変わる」機能** を紹介します。

---

## プランモード

**「いきなり実装しないで、先に計画だけ立てて」** という時に使います。

### 使い方

Claude Code 起動中に **`Shift + Tab` を2回押す** とプランモードに切り替わります（画面上部に `plan mode on` のような表示）。

この状態で指示を出すと、**実際には変更せず、計画だけを提示** してくれます。

```
plan mode > Bot の応答メッセージを「考え中...」に変更したい
```

→ Claude Code「次のステップで行います：1) server.mjs を読み...」のように計画を出す。

良ければ「実行して」、違うなら「ここを変更して」と修正できます。

### いつ使うか

- **大きな変更** をするとき：影響範囲を先に見たい
- **不安な作業** をするとき：実行前にチェックしたい
- **学習目的** で：何をやろうとしているか理解したい

---

## TODO リスト機能

Claude Code は **複数ステップの作業を「TODO リスト」として管理** します。

たとえば「README を整える」と言うと：

```
☐ README.md を読む
☐ プロジェクト概要を書く
☐ セットアップ手順を書く
☐ 使い方を書く
☐ 環境変数の説明を追加
```

…のように一覧で進捗が見えます。**完了した項目はチェックされていく** ので、安心して長い作業を任せられます。

---

## サブエージェント

**サブエージェント** は「特定の仕事に特化した補助 AI」です。

メイン会話とは別の "助手" を呼んで作業を任せられます。並列で動かせるので、**大きな調査を高速化** できます。

### 使ってみる

```
このプロジェクト全体を読んで、「テストが書かれていない部分」を探して、一覧にして
```

このような **横断的な調査** で、Claude Code は内部的に "Explore" というサブエージェントを呼びます。本体の文脈を汚さずに、結果だけ持ち帰ってくれます。

### `/agents` で確認

```
/agents
```

使えるサブエージェントの一覧と、自分でカスタム作成する画面に行けます。

---

## 並列実行

Claude Code は「依存しない作業」を **同時並行** で進められます。

```
README.md と CHANGELOG.md を、それぞれの内容に応じて初期化して
```

→ 内部的に2つを並列で作成。「片方終わってから次」ではなく **同時** に進むので速いです。

---

## バックグラウンド実行

長い作業（サーバー起動、テスト実行など）は **バックグラウンド** で動かせます。

```
npm run dev をバックグラウンドで起動して、起動ログだけ確認して
```

Claude Code はサーバーを起動しつつ、別の作業を続けられるようになります。

---

## チェックポイント / ロールバック

Claude Code は **「ここに戻りたい」という瞬間に戻れる** チェックポイント機能を持っています。

たとえば、何度かやり取りを重ねて「あ、3つ前の状態が一番良かった」と思った時、特定のメッセージまで戻れます。

> 💡 git とは別の仕組みで、**ファイルの状態ごと** 巻き戻せます。詳しくは `/help` で「checkpoint」を検索してみてください。

---

## 画像を貼り付け

エラー画面のスクショや UI のモックアップを **そのままターミナルに貼り付け** できます。

```
（スクショを貼り付け）
↑この画面のエラーを直して
```

Claude Code が画像を読み取って、エラー内容や UI 要素を理解してくれます。

---

## Web 検索・取得

最新情報が必要なときは Web を見に行けます。

```
LINE Messaging API の最新のレート制限を調べて、CLAUDE.md に追記して
```

→ Web で公式ドキュメントを確認 → CLAUDE.md に追記、まで一気にやってくれます。

---

## ステータスライン

画面下にある **ステータスライン**（モデル名、使用トークン数などが出る部分）はカスタマイズできます。

```
/config
```

から設定するか、`/statusline` 系の設定で自分好みに変更できます。

---
