## A. Claude Code そのもののトラブル

### A-1. `claude` コマンドが見つからない

```
command not found: claude
```

**対処**：
1. ターミナルを一度閉じて開き直す
2. それでもダメなら再インストール：`npm install -g @anthropic-ai/claude-code`
3. Mac/Linux なら `which node` で Node.js のパスを確認
4. `npm root -g` で Claude Code のインストール先を確認

### A-2. ログインできない

- ブラウザで URL が開かない → 表示された URL を手動でコピペ
- 認証コードを貼っても進まない → `claude /logout` で一度ログアウトしてやり直し

### A-3. 動作が遅い、止まる

- `Ctrl + C` 2回で強制終了 → 再起動
- 会話が長すぎる可能性。`/clear` で会話を切る
- モデルを軽いものに：`/model` で Sonnet や Haiku に切り替え

### A-4. 料金が気になる

```
/cost
```

で確認。減らしたい場合は：

- 不要な長文を貼らない
- `/clear` で会話を切ってから新しい話題を始める
- 簡単なタスクは Haiku に切り替える

## B. このプロジェクトのトラブル（line-group-bot）

CLAUDE.md にも書いてありますが、頻出のものをまとめます。

### B-1. `Invalid signature` エラー

**原因**：`LINE_CHANNEL_SECRET` が間違っている

**対処**：LINE Developers Console で再確認して `.env` を直す

### B-2. `Invalid reply token`

**原因**：返信トークンの期限切れ（30秒以内に返さないと無効になる）

**対処**：処理を高速化。Claude Code に「`handleEvent` の高速化を提案して」と聞く

### B-3. `SPREADSHEET_ID が未設定`

**対処**：`.env` に `SPREADSHEET_ID=...` を追加

### B-4. `トークンファイルが見つかりません`

**対処**：`credentials/tokens.json` を準備（Google OAuth フローを完了する）

## C. Claude Code への指示がうまく伝わらない

### C-1. 「思ったのと違うコードが書かれた」

- **対象を絞る**：「`server.mjs` の `handleEvent` だけを変えて」
- **条件を足す**：「既存のロジックは壊さずに」「コメントは日本語で」
- **元に戻す**：`git checkout <ファイル名>` で戻して再挑戦

### C-2. 「会話が長くなりすぎて混乱している」

```
/clear
```

で記憶をリセット。CLAUDE.md に重要な前提を書いておけば、`/clear` しても引き継がれます。

### C-3. 「Claude Code が勝手にいろいろやって怖い」

**プランモードを使いましょう**。`Shift + Tab` を2回押してから指示すると、計画だけ立てて停止します。

### C-4. 「何をやっているか分からない」

```
今やろうとしていることを、初心者向けに日本語で説明してから進めて
```

と最初に頼むと、行動の前に説明を挟むようになります。

## D. git まわりのトラブル

### D-1. 「ファイルを変なふうに変えてしまった」

```bash
git status                # 変更されたファイルを確認
git diff <ファイル名>     # 変更内容を確認
git checkout <ファイル名> # 変更を取り消す（注意：作業が消えます）
```

### D-2. 「コミットを取り消したい」

```bash
git log --oneline        # コミット履歴を見る
git reset HEAD~1         # 直前のコミットを取り消す（ファイルの変更は残る）
```

> ⚠️ `git reset --hard` は **作業内容ごと消える** ので慎重に。

### D-3. 「Claude Code がコミットしてくれない」

明示的に「コミットして」と頼まないとコミットしません。これは **安全のための仕様** です。

```
変更をコミットして
```

と頼むとやってくれます。
