# 03. 初めての対話

セットアップが終わったら、いよいよ Claude Code と会話してみましょう。

この章では「コードに手を入れずに、ただ質問する」ことだけをやります。**読む** ところから始めるのが安全だからです。

---

## 起動の確認

`line-group-bot` フォルダで `claude` と打って起動しておきましょう。

```bash
cd ~/line-group-bot
claude
```

以下のような画面になっているはずです（バージョンによって見た目は変わります）。

```
 ╭─────────────────────────────────╮
 │ Claude Code v...                │
 │ Working in /Users/.../line-... │
 ╰─────────────────────────────────╯

>
```

`>` の右側に日本語で指示を書きます。

---

## 演習1: プロジェクトを説明してもらう

最初の指示はこれにしましょう。

```
このプロジェクトは何をするものか、CLAUDE.md を読んで日本語で要約して
```

Enter を押すと、Claude Code は：

1. `CLAUDE.md` を読みに行く
2. 内容を理解する
3. 要約してあなたに返す

…という流れで動きます。**あなたが「ファイルを開け」と細かく指示する必要はありません**。

> 💡 Claude Code がファイルを読むときは「Read ツールを使った」みたいな表示が出ます。これは「裏で実際に作業した記録」なので、気にしなくて OK です。

---

## 演習2: 構成を可視化してもらう

```
このプロジェクトのフォルダ構成を、ツリー図で見せて
```

`server.mjs` や `lib/ai.mjs` がどこにあるか、見える形で返ってくるはずです。

---

## 演習3: 個別ファイルの役割を聞く

```
server.mjs は何をやっているファイル？ 初心者にも分かるように説明して
```

「`server.mjs` は LINE からのメッセージを受け取って…」のように、コードを読み解いて説明してくれます。

> 💡 **コツ**：「初心者にも分かるように」「専門用語を使わずに」と添えると、説明が優しくなります。

---

## 演習4: 用語をその場で聞く

説明の中に分からない単語が出てきたら、すぐ聞きましょう。

```
「Webhook」って何？ 例えで説明して
```

```
「環境変数」って何？ なぜ .env というファイルに書くの？
```

**Claude Code は会話を覚えているので**、前のやり取りを踏まえて答えてくれます。

---

## 良い指示の書き方

| ❌ よくない | ✅ 良い |
|---|---|
| 「説明して」 | 「`server.mjs` の `handleEvent` 関数を、日本語で説明して」 |
| 「直して」 | 「ログに出る `Invalid signature` エラーを直して。原因も教えて」 |
| 「やって」 | 「`.env.example` を参考に、`.env` ファイルを作って」 |

**3つの要素** を意識すると、指示が伝わりやすくなります。

1. **対象**：何のファイル / 関数 / 機能か
2. **動作**：説明・修正・作成・実行のどれか
3. **条件**：どんな結果が欲しいか（日本語で、初心者向けに、テスト付きで、など）

---

## 会話履歴の管理

Claude Code との会話は、終了しても残ります。次のコマンドが便利です。

| コマンド | 意味 |
|----------|------|
| `claude` | 新しい会話を開始 |
| `claude --continue` または `claude -c` | 直前の会話を再開 |
| `claude --resume` または `claude -r` | 過去の会話を一覧から選んで再開 |

> 💡 一度終了しても `claude -c` で続きから再開できると覚えておきましょう。

---

## 中断したいとき

Claude Code が長く動いて「あ、違うな」と思ったら：

- **`Esc` キー**：今の作業を止める
- **`Ctrl + C`**：強制中断
- **`Ctrl + C` を2回**：Claude Code を終了
