FAQ

よくある質問

本当にプログラミング未経験でも大丈夫？ +

はい。ターミナルの開き方から説明しています。「分からない言葉」は Claude Code 自身に質問しながら進められるので、教材を読んでわからなくても止まりません。

Mac と Windows どちらでも使える？ +

両方で動きます。02章のセットアップで、それぞれの OS での操作を説明しています。

料金はかかる？ +

教材自体は無料です。Claude Code を動かすには Claude Pro（月20ドル程度）または API 利用料が必要です。詳しくは 01章で説明しています。

どれくらいで身につく？ +

通読するだけなら 2.5 時間ほど。実際に手を動かしながらなら、1 日 30 分 × 1 週間が目安です。

line-group-bot を使わないと学べない？ +

いいえ。題材として使っているだけなので、概念は他のプロジェクトにそのまま応用できます。自分の好きなプロジェクトで試しながら読んでも OK です。
