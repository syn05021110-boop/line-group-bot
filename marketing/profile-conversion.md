# プロフィール改修（転換仕様）— 閲覧→フォロー→LINE を最大化

## 前提（実データ）
- 月間 閲覧者 3,787人（うち非フォロワー 3,702）＝リーチは十分ある
- 純フォロワー +10人（転換率0.26%）＝ここが唯一の漏れ
- → プロフィール＝3,700人が"来るかもしれない受け皿"。ここを直すと数字が動く

## 表示名
`Mao｜AIで会社員の副業を仕組み化`

## bio（プロフィール文）
```
会社員×AIで副業を"仕組み化"｜難しいプロンプト不要で、強みの言語化→発信→収益化を時短｜元○○→発信で人生変え中｜
🎁 AI発信スターターキット 無料配布中 ↓
```
※「元○○」は実際の前職。最終行がリンクへの誘導理由になる。

## リンク（プロフィールのリンク欄）
- **LINE公式が用意できていれば → LINEのURL**（登録で無料プレゼントを配布＝リード獲得）
- まだなら暫定で → 無料プレゼントpage か アプリURL

## 固定投稿（転換仕様・これを非フォロワーが見る）
```
【フォローする前に読んでください】

「AIで副業、気になるけど難しそう」
——数年前の私です。

でも分かったのは、AIは"難しいプロンプト"じゃなく、
"自分のことを話して質問させる"だけで
発信も副業も一気にラクになるということ。

このアカウントでは、会社員が
・自分の強みをAIで言語化して
・発信を仕組み化して
・消耗せずに副業を育てる
やり方を、毎日わかりやすくシェアします。

「何を発信すればいいか分からない」人ほど、
フォローして損はさせません。

🎁 無料プレゼント
「AI発信スターターキット」
（強みを引き出すプロンプト＋バズる投稿の型＋1週間テンプレ）
受け取りはプロフィールのリンクから↓

保存＆フォローで、明日から一緒に動き出しましょう。
```

## 仕上げのコツ（転換率を上げる小技）
- 投稿の締めに時々「保存＆フォローで見返して」を入れる（フォロー動機）
- 「明日は○○を出します」で継続視聴＝フォロー誘導
- 数投稿に1回、無料プレゼントに触れる（毎回はしない＝宣伝臭を避ける）
- 会話型（質問・二択）は継続（コメント44件の実績あり）
