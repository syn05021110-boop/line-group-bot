## 全体の流れ
```
note（無料プレゼント）/ Threads
  ↓ 友だち追加
① あいさつメッセージ … キットのURL＋「特典」の受け取り方＋サポートの案内
  ↓ 「特典」と送る
② キーワード応答「特典」 … LINE限定プロンプト5本
  ↓ 登録から1・3・5日後
③ ステップ配信 … 教育 → 副業ドラフト案内
（並行して）④ キーワード応答 … 使い方／開けない／やり直し／note のサポート
```

## 設定する場所
| 何を | 管理画面の場所 |
|---|---|
| ① あいさつメッセージ | ホーム → 自動応答 → あいさつメッセージ |
| ② ④ キーワード応答 | ホーム → 自動応答 → 応答メッセージ → 作成 →「キーワード応答」 |
| ③ ステップ配信 | ホーム → ステップ配信 |

- キーワード応答は **完全一致** でしか反応しない。だからあいさつで「そのまま送ってね」と言葉を指定する
- あいさつメッセージと応答メッセージは、メッセージ通数に数えられない。**ステップ配信は通数に数えられる**ので、プランの月間上限を管理画面で確認しておく

## ④ サポート用キーワード応答（既存を書き直し）

既存の「使い方」「note」「やり直し」は、実際のアプリにない動き（「5つ答えると1週間分が完成」「note も作りますか？と聞かれる」「もっと刺さる版にしてと伝えると再生成」）を説明していた。アプリのコード（`app/`）で確認した実際の動きに合わせる。

### 「使い方がわからない系」（キーワード：使い方／やり方／操作／どうすれば）
```
副業ドラフトの基本の流れです👇

STEP1：ツールを開いて「ヒヤリングを始める」を押す
STEP2：AIの質問に、思いつくまま答える（目安3〜5分）
STEP3：材料が集まると、自動で「強み棚卸し」が表示される
STEP4：「この強みで下書きを作る」→「Threads」を押す

無料では、Threadsの下書き3本まで作れます。
X・Instagram・note・1週間カレンダーなどは有料プランです。

どこで止まっているか教えていただければ、詳しくご案内します！
```

### 「やり直したい」（キーワード：修正／やり直し／訂正／もう一度／変えたい／もう一回）
```
作り直したいときはこちら👇

■ 下書きの方向性を変えたい
→「テーマ」欄に書きたい方向を入れて（例：未経験から副業を始める人向け）、
もう一度「Threads」を押してください。

■ ヒヤリングから最初にやり直したい
→ ページを再読み込みすると、最初からやり直せます。
（それまでの会話は消えるので、残したい下書きは先にコピーしてください）

うまくいかない場合は、状況を教えてください🙇
```

### 「noteについて」（キーワード：note／下書き／記事）
```
note記事の下書きについてです👇

note下書きと有料noteの構成案は、有料プランの機能です。
強み棚卸しのあと、「note 下書き」のボタンから作れます。

無料では、まずThreadsの下書き3本で試せます。
有料プランの内容は、ツール内の「全機能を解放」から確認できます。
```
