## 返信1（メイン投稿のスレッドにつなげる）

```
安全面で決めたこと。

・受け付けるのは自分の投稿だけ
・コマンドを実行する前に、スマホに承認ボタンが届く
・削除や外部への送信、パスワードの入ったファイルの読み取りは最初から禁止

「スマホから自分のPCが動く」は、乗っ取られたら危ないのと同じ意味なので、ここは最初に固めた。
```

### 単発2

```
Claude Code が自動で更新されたら、ログインが外れてた。

画面に「API Usage Billing」の文字。
ここで API のほうでログインすると、月額とは別に使った分だけ課金される。

月額プランの人は「subscription」のほうを選ぶ。これ大事。
```

### 単発3

```
AIツールを入れるときに最初に言うようにしてること。

「この情報は動画で見たものだから、名前も機能も正確とは限らない。公式で確かめてから入れて」

これを言うだけで、知らないコマンドを自分のPCで実行する怖さがかなり減る。
```
