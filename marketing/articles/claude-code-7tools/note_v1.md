# 動画で見た「AIツール7つ」を、全部本当に入れてみた。スマホから自宅のMacに仕事を頼めるようになるまで

（見出し画像：images/note_01_eyecatch.png）

---

Discord の自分専用のチャンネルに、短いメッセージを打ちました。

少しすると返事が届きました。返事をしたのは人ではありません。自分の Mac で動いている Claude Code です。

プログラミングの経験はありません。本業は現場で働く会社員で、副業で業務の効率化や AI 活用の手伝いをしています。その自分が、ある動画で紹介されていた「Claude Code に入れておくと便利な7つの機能」を、数時間かけて全部入れました。この記事はその記録です。

ハマったところも、隠さずに書きます。

## 動画の名前をそのまま信じない、から始めた

紹介されていたのは次の7つでした。

- Canva（サムネイルやバナーを作る）
- HyperFrames（指示から動画を組み立てる）
- Superpowers（作業の前に計画を立て、段階的に進め、最後にレビューする）
- browser-use（ブラウザを操作して情報を集める）
- frontend-design（サイトや画面の見た目を良くする）
- Discord 連携（スマホから指示を送り、PC で実行して結果を受け取る）
- skill-creator（繰り返す作業を「スキル」として登録する）

最初に Claude Code へ頼んだのは、インストールではありませんでした。「動画の情報なので、名前も機能も正確とは限らない。公式のドキュメントや開発元のリポジトリで、本当にあるのか確かめてから入れてほしい」と伝えました。

ネットで見た「このコマンドを打てばOK」を、そのまま自分のPCで実行するのが怖かったからです。

結果は、7つとも実在しました。すべて Anthropic 公式のプラグイン一覧に載っていて、提供元もはっきりしていました。Canva は Canva 社、HyperFrames は HeyGen 社、browser-use は Browser Use 社が出しています。

意外だったのは skill-creator です。これは最初から使える状態になっていました。同じ機能を二重に入れると混乱のもとなので、これだけは入れていません。

（画像：images/note_02_tools.png）

## 入れて、ちゃんと動くかまで確かめた

入れただけで終わらせず、機能ごとに小さく試してもらいました。

HyperFrames では「job-scout 動作確認」という文字が浮かび上がる3秒の動画を作り、日本語がきちんと表示されるところまで確認しました。browser-use は、試験用のブラウザで Web ページを開き、見出しを読み取れることを確かめました。試したあとのブラウザは閉じています。

Canva は、自分の Canva アカウントでログインするだけでした。つないでみると、デザインの作成、編集、サイズ変更、書き出しなど、40種類の操作が使えるようになっていました。

## いちばん手間がかかったのは、Discord だった

7つのうち、手間の大半は Discord 連携でした。そして、これがいちばん「生活が変わる」機能でもありました。

仕組みはこうです。自分しかいない Discord サーバーを作り、そこに自分専用の Bot を置きます。スマホからそこに書き込むと、自宅の Mac で動いている Claude Code に届きます。Claude Code が作業して、結果を Discord に返してくれます。

（画像：images/note_03_flow.png）

便利な反面、「スマホから自分のPCを動かせる」ということは、乗っ取られたら危ないということでもあります。そこで、始める前に次のように決めました。

- 受け付けるのは自分の投稿だけ。他人の書き込みは無視する
- コマンドを実行する前に、スマホに承認ボタンが届くようにする
- 削除や外部への送信など危ない操作と、パスワードなどが入ったファイルの読み取りは、承認しても動かないよう最初から禁止する
- Bot の鍵（トークン）は、チャットに貼らず PC の中だけに保存する

設定は Claude Code がやってくれました。ただ、Discord 側の画面を操作するのは自分です。そこで4回つまずきました。

（画像：images/note_04_pitfalls.png）

**1つ目は、公開 Bot のスイッチです。** 「誰でも Bot を追加できる」状態を切っておこうとオフにしたら、「プライベートアプリにはデフォルトの認証リンクを設定できません」という赤いエラーが出ました。先に「インストール」の画面で、インストールリンクを「なし」にしておく必要がありました。

**2つ目は、トークンの貼り付けです。** 貼っても画面に何も表示されない仕組みだったので、うまくいったのか分からず、2回貼ってしまいました。トークンが2つつながって保存され、Bot が動きません。Claude Code が中身を表示しないまま長さと形だけを調べて原因を見つけ、正しい1つだけを残してくれました。

**3つ目は、書き込む場所です。** 「返信が来ない」と焦りましたが、原因は単純で、Bot への DM ではなくサーバーのチャンネルに書き込んでいました。安全のため、許可していない場所の投稿は無視する設定にしていたからです。そのチャンネルを「自分の投稿だけ」という条件で許可したら、すぐに返事が来ました。

**4つ目は、Canva をつなぐときです。** ターミナル版の Claude Code が自動で最新版に更新され、ログインが外れていました。画面には「API Usage Billing」（使った分だけ課金）の表示も出ていました。ここでうっかり API でログインすると、月額プランとは別にお金がかかります。月額プランのアカウントでログインし直してから進めました。

どれも、分かってしまえば一瞬で直ることです。ただ、初めてだと画面の前で止まってしまいます。

## 入れてみて、何が変わったか

いちばん大きいのは、「PCの前に座らないと何も進まない」状態から抜け出せたことです。

平日の日中は本業で手が離せません。それでも、休憩中にスマホから「案件を探して、件数を教えて」と書いておけば、その間に Mac が作業を進めてくれます。

Canva と HyperFrames が入ったので、こうした発信に使う画像や短い動画づくりも、同じ流れで頼めるようになりました。この記事の図も、Claude Code に作ってもらいました。

## これから始める人へ

ツールを入れること自体は、正直なところ難しくありませんでした。むずかしかったのは、次の3つです。

- 動画や記事の情報を、公式の情報と照らし合わせること
- 便利さと引き換えに、どこまで任せてよいかを決めること
- 途中でつまずいたときに、原因を切り分けること

そしてもう1つ、ツールを入れたあとに必ず出てくるのが「で、何を発信するのか」という問題です。

## 発信が止まる理由は、だいたいネタと下書き

ここからは宣伝です。

副業の発信を続けようとして止まるのは、ツールの使い方よりも「自分の何を書けばいいか分からない」「下書きを作る時間がない」ところだと思います。

そこで作ったのが「副業ドラフト」というツールです。AIの質問に3〜5分答えるだけで、副業に使える自分の強みを棚卸しし、そこから Threads と note の下書きを作ります。

（画像：images/note_05_draft.png）

無料で使えるのは、ヒヤリング、強みの棚卸し、Threads の下書き3本までです。自分の強みが何なのか、まず試してみてください。
