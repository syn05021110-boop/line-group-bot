## 単発投稿（日を分けて出す用）

### 単発1（型の紹介）

```
発信の書き出しで迷ったら、型に当てはめるだけでいい。

・数字型「○○の9割が、△△を知らない」
・逆張り型「□□はやめた方がいい。理由は—」
・告白型「正直に言うと、◯◯で失敗しました」
・保存型「【保存版】◯◯なとき用リスト」
・二択型「①か②、どっち派？」

残り5つはプロフィールのリンクから。
```

### 単発2（指示のコツ）

```
AIに「いい感じにして」と頼むと、だいたいいい感じにならない。

渡すのはこの4つ。
【誰に】○○な人向けに
【何を】△△について
【トーン】□□な感じで
【長さ】120字で

これだけで出てくる文章が別物になる。
```

### 単発3（仕組み化）

```
発信が続かないのは、意志が弱いからじゃなくて、毎回ゼロから考えてるから。

1テーマをAIに「10の切り口に分解して」と頼めば、1ネタが10投稿になる。
週末30分でまとめて作って、平日は出すだけ。
```
