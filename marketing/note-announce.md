# note告知文（Threads / X）— 公開済みnote → 各SNSで回遊

狙い：noteを出したら各SNSで告知して相互送客。1記事が何投稿にもなる。

## 📌 投稿のコツ（重要）
- **Threadsは本文にURLを貼ると拡散が落ちる** → URLは**1件目のリプ**に貼る（本文は「詳しくはリプのnoteに」）
- **Xはリンク併記でOK**
- 告知は"押し売り"にしない。まず価値を1つ渡して「続きはnoteで」

## 運用メモ
- 1記事につき告知は1回で終わらせない。**角度を変えて2〜3回**（当日・数日後・1週間後）
- 反応が良かった告知文は、そのまま次の記事にも流用
- noteの末尾CTA（LINE登録）と合わせて、告知→note→LINEの流れを作る
