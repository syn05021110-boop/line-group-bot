# Threads 量産 第1弾（20本）

2026-09-28 の壁打ち・作業で出た**実話だけ**を材料にしている（作り話・数字の盛りなし）。
名義は @shachiku_mao。別アカウントの名前は出さない。1投稿500字以内・タグなし（必要なら投稿時に1つだけ）。
使い方：手動で1日1本ずつ出すか、自動投稿の順番待ち（`app/data/threads-queue.json`）に入れる。

---

## 01 告白型（売上ゼロ）
```
正直に言います。

自分で作ったAIツール、売上ゼロです。
利用者もゼロ。

しかも今日わかったんですが、
AIの鍵の期限が8月に切れてて、
たぶん7週間くらい、誰も使えない状態でした。

売れない以前に、動いてなかった。

自分の商品を、客として最後まで触ってなかったんですよね。

みんなは自分の商品、最近お客さん目線で触ってますか？
```

## 09 数字型（伸びた投稿の構成）
```
それまでは反応100にも届かない投稿ばかりだったのに、
1本だけ6.4万回表示された。

やったのは、伸びてる投稿の「構成」を真似しただけ。

ポイントは、フォロワー数百万の人じゃなくて、
フォロワー数百人なのに伸びてる投稿を探すこと。

有名人の投稿は、フォロワーの力で伸びてる。
数百人の人の投稿は、構成の力で伸びてる。

真似するなら、後者。
```

## 10 保存型（伸びた構成の分解）
```
【保存版】コメントが1,000件以上ついた投稿の構成

1. 呼びかけで止める
2. 何が始まるか一言で宣言
3. 「〜でいい」で参加のハードルを下げる
4. 読んだ人の気持ちを言い当てる
5. 自分も同じ側だと言う
6. コメントする言葉を指定する
7. 自虐で締める

特に6が効いた。
「なんて書けばいいか」を決めてあげると、人はコメントしてくれる。
```
