## 1. 全体の流れ

[[img:p02_flow.png]]

最初に、完成形を見てください。

1. note や Threads から、LINEを友だち追加してもらう
2. **あいさつメッセージ**（自動）：無料プレゼントのURL、「特典」の受け取り方、困ったときの送り方を案内
3. 「特典」と送ってもらう → **キーワード応答**で、LINE限定のプレゼントが届く
4. 友だち追加から1日後・3日後・5日後に、**ステップ配信**が届く（考え方 → コツ → 自分のツールの案内）
5. 並行して、**リッチメニュー**と**サポート用のキーワード応答**で、いつでも案内を受け取れるようにする

使っている機能は、すべてLINE公式アカウントの標準機能です。
設定は LINE Official Account Manager（パソコンのブラウザで開く管理画面）でやりました。

ちなみに私は、文面を考えるのと、管理画面への入力を Claude Code に手伝ってもらいました。
ただ、やっていること自体は画面をクリックして文字を貼るだけなので、手作業でも同じようにできます。

## 2. 設定する場所の一覧

管理画面で迷わないように、場所を先にまとめておきます。

- **あいさつメッセージ**：ホーム → 自動応答 → あいさつメッセージ
- **キーワード応答**：ホーム → 自動応答 → 応答メッセージ → 作成 →「キーワード応答」を選ぶ
- **一律応答**（どのキーワードにも当てはまらないときの返事）：同じく応答メッセージの中
- **ステップ配信**：ホーム → ステップ配信
- **リッチメニュー**：ホームの左側のメニューにある「リッチメニュー」
- **応答時間・応答方法**：設定 → 応答設定

※ LINEの管理画面は、ときどき表記や並び順が変わります。見つからないときは、画面の検索や左メニューを上から順に見てください。

作る順番は、この記事の見出しの順がおすすめです。
あいさつで「特典と送ってね」と案内するので、**先に「特典」のキーワード応答を作っておく**と、テストしやすくなります。

## 3. キーワード応答「特典」を作る

### 設定のしかた

1. ホーム → 自動応答 → 応答メッセージ → 作成
2. 種類で「キーワード応答」を選ぶ
3. タイトル：`特典`（管理用の名前。友だちには見えません）
4. キーワード：`特典` `とくてん` `プレゼント` `追加特典`
5. 本文を吹き出し2つで入れる
6. 保存して、「利用中」になっているか確認する

キーワードを4つ登録しているのは、あとで書く「完全一致」の対策です。
ひらがなで送る人、「プレゼント」と送る人も拾えるようにしています。

### テンプレート：吹き出し1

```
LINE限定の追加特典です🎁
【プレゼントの説明：例「〇〇から、無料プレゼントに入っていない5本を選びました」】
【使い方：例「AIにそのまま貼って使えます」】

① 【タイトル】
【中身】

② 【タイトル】
【中身】

③ 【タイトル】
【中身】

④ 【タイトル】
【中身】

⑤ 【タイトル】
【中身】
```

私の場合、中身は「AIにそのまま貼って使えるプロンプト5本」にしました。
無料プレゼントの note に入っていないものを選んで、「LINEに来た意味」があるようにしています。

中身が長いなら、全文を貼らずに note や PDF のURLにしてもかまいません。

### テンプレート：吹き出し2

```
まずは①を1回だけ試してみてください。
【試すと何が起きるか：一文で】

【次の一歩の案内：例「〇〇まで自動でやってほしい方は、無料で試せるツールもあります」】👇
【URL】
（【無料でできる範囲を正直に書く】）
```

2つ目の吹き出しで、次の一歩を一つだけ置いておきます。
ここで大事なのは、**無料でどこまでできるかを正直に書く**ことです。
「無料で使えます」だけだと、途中で有料の画面が出たときにがっかりさせてしまいます。

## 4. あいさつメッセージ（吹き出し3つ）

### 設定のしかた

1. ホーム → 自動応答 → あいさつメッセージ
2. 吹き出しを3つにして、下の文面を入れる
3. `{Nickname}` と `{AccountName}` は、画面の「友だちの表示名」「アカウント名」のボタンから挿入すると、送るときに自動で名前に置き換わります

### テンプレート：吹き出し1（あいさつ＋無料プレゼント）

```
{Nickname}さん、友だち追加ありがとうございます！
{AccountName}です🙌

このLINEでは、【誰に】【何を】お届けしています。

まだ読んでいない方は、無料プレゼントからどうぞ👇
🎁 【無料プレゼントの名前】
【無料プレゼントのURL】
```

### テンプレート：吹き出し2（特典の受け取り方）

```
🎁 LINE限定の追加特典

「特典」と送るだけで、
【何が届くか：例「無料プレゼントに入っていない〇〇が5本」】届きます。
```

### テンプレート：吹き出し3（困ったときの送り方）

```
📱 【サービス名】を使っている方へ
下のことばを「そのまま」送ると、すぐに案内が届きます。

「使い方」…基本の流れ
「開けない」…【サービス】が開かないとき
「やり直し」…作り直したいとき
「【4つ目のことば】」…【何の案内か】

それ以外は、そのままメッセージを送ってください。
①どの画面で ②何をして ③どうなったか
を添えてもらえると早く対応できます。
※返信は基本【24時間以内】です。
```

### 3つに分けた理由

1つの吹き出しに全部詰めると、長すぎて最後まで読まれません。
なので、役割ごとに分けました。

- 吹き出し1：あなたは誰で、ここで何がもらえるか
- 吹き出し2：特典の受け取り方（一番やってほしい行動）
- 吹き出し3：困ったときの窓口

吹き出し3の「そのまま送ると」という一言と、送ることばをカギかっこで見せているのには理由があります。
次の章の「完全一致」の話につながります。

## 5. 落とし穴①：キーワードは「完全一致」でしか反応しない

[[img:p02_keyword.png]]

ここが一番はまりやすいところです。

LINE公式のキーワード応答は、**送られてきた文字が、登録したキーワードとぴったり同じときだけ**反応します。

たとえば、キーワードに「開けない」を登録していても、

- 「開けない」 → 反応する
- 「ツールが開けないです」 → 反応しない
- 「開けません」 → 反応しない

反応しなかったメッセージには、一律応答（どのキーワードにも当てはまらないときの返事）が返ります。
一律応答を作っていなければ、何も返りません。

見直す前の私のLINEは、ここが考えられていませんでした。
困った人が普通の文章で送ってくると、ほぼ全部が一律応答になる作りでした。

### 私がやった回避策

完全に防ぐ方法はないので、「ぴったりの言葉を送ってもらう」工夫を3つ重ねました。

1. **あいさつで、送ることばを指定する**
   「特典」と送るだけで、「使い方」…基本の流れ、のように、カギかっこで送る言葉を見せる。「そのまま送ると」と書く
2. **リッチメニューのボタンから、正確な言葉を送らせる**
   ボタンを押すと、キーワードと同じ文字が自動で送られるように設定する（7章で説明します）。これなら入力ミスが起きません
3. **ゆれそうな言い方を、キーワードに足しておく**
   「特典」なら「とくてん」「プレゼント」「追加特典」も登録。「やり直し」なら「修正」「もう一度」「もう一回」なども登録

それでも当てはまらないときのために、一律応答で「人が読んで返事をします」と伝えておけば、送った人が放置されることはありません。

### テンプレート：一律応答

```
メッセージありがとうございます！
内容を確認して、【24時間以内】にお返事します。

お急ぎの方は、下のことばを「そのまま」送ると、すぐに案内が届きます。
「使い方」「開けない」「やり直し」
```

※ 私の一律応答は、前から使っていた「24時間以内に返信する」という文面のままです。上は、それを読みやすく整えた例です。

## 6. 落とし穴②：応答時間の設定で、自動応答が出ない

これも、気づかないと「設定したのに動かない」になります。

LINE公式には「応答時間」という設定があります。
チャットで人が返事をする時間帯を決めるものです。

私のアカウントでは、**応答時間内は「手動チャット」だけ**になっていました。
つまり、その時間帯に「特典」と送られても、キーワード応答が出ず、人が返事をするまで待たせる設定です。

自分では「キーワード応答を作ったから大丈夫」と思っていても、送る時間によっては動かない、ということが起きます。

### 直し方

1. 設定 → 応答設定
2. 応答方法の「応答時間内」を、**「手動チャット＋応答メッセージ」**に変える
3. 「応答時間外」も、応答メッセージが出る設定になっているか確認する

これで、時間帯に関係なく「特典」と送ればプレゼントが届き、それ以外のメッセージにはチャットで返事もできる状態になりました。

※ 設定の名前や選択肢は、管理画面の更新で変わることがあります。「応答時間内に、応答メッセージが出る設定になっているか」を見てください。

## 7. リッチメニュー（6つのボタン）

[[img:p02_richmenu.png]]

トーク画面の下に出るボタンのメニューです。
あいさつメッセージは友だち追加のときに1回流れるだけなので、あとから「特典ってどう受け取るんだっけ」となった人のために、いつでも押せる場所を作っておきます。

### ボタンの配置

大きいサイズの6分割テンプレートを使いました。

- 左上：**特典を受け取る**（ここだけ黄色で目立たせる）→ テキスト「特典」を送る
- 真ん中上：**無料キット** → 無料プレゼントの note を開く
- 右上：**副業ドラフト**（自分のツール）→ ツールのページを開く
- 左下：**使い方** → テキスト「使い方」を送る
- 真ん中下：**作り直したい** → テキスト「やり直し」を送る
- 右下：**うまく開けない** → テキスト「開けない」を送る

考え方はシンプルです。

- 上の段：もらう・読む・試す（来てくれた人がやりたいこと）
- 下の段：困ったとき（サポート）
- 一番やってほしい「特典を受け取る」を、左上に置いて色を変える

### いちばん大事な設定：テキストはキーワードと同じにする

左上・左下・真ん中下・右下のボタンは、「テキスト」のアクションにしています。
ボタンを押すと、その文字がトークに自動で送られます。

ここで送る文字を、**キーワード応答のキーワードとまったく同じ**にしておきます。
「特典」「使い方」「やり直し」「開けない」です。

こうすると、ボタンを押す → キーワードとぴったり同じ文字が送られる → 自動で案内が届く、という流れになり、完全一致の問題を気にしなくて済みます。

逆に言うと、**あとでキーワードを変えたら、リッチメニューのテキストも必ず合わせる**必要があります。ここがずれると、ボタンを押しても一律応答しか返らなくなります。

ボタンの見出し（作り直したい）と、送る文字（やり直し）は違っていてもかまいません。見出しは押す人に分かりやすい言葉、送る文字はキーワードに合わせる、と分けて考えます。

### 画像の作り方

リッチメニューの画像は、2500×1686ピクセル（大・6分割）で作りました。

作り方は、ざっくりこうです。

1. AIに「6つのボタンのメニュー画像を、HTMLで作って」と頼む（サイズ・ボタンの文字・色を指定）
2. できたHTMLを、ブラウザで画像（PNG）として書き出す
3. 管理画面で、テンプレート「大・6分割」を選んで画像をアップロードする

デザインで気をつけたのは、これだけです。

- **画像のマス目を、LINEの6分割テンプレートのタップ範囲とぴったり合わせる**。ずれると、見た目と押した場所の反応が食い違います
- 1マスに、アイコン・大きい見出し・小さい説明の3つだけ
- 背景は濃い紺、文字は白、強調は黄色。色を増やさない
- 見出しは短く。スマホで見ると、画像はかなり小さくなります

Canva などのデザインツールに、LINEのリッチメニュー用のサイズがあれば、それを使っても同じものが作れます。

※ 画像は大サイズなら 2500×1686 など、決まったサイズで作ります。私が登録したときの管理画面の案内では、ファイルサイズは10MB以下でした（変わることがあるので、画面の案内も確認してください）。

### 私が入れたその他の設定

- タイトル：管理用の名前（友だちには見えません）
- 表示期間：開始日から数年先まで（途中で消えないように長めに）
- メニューバーのテキスト：「メニュー」
- メニューのデフォルト表示：「表示する」（トークを開いたときに最初から開いている）

## 8. ステップ配信（1日後・3日後・5日後）

友だち追加した日を起点に、決まった日数後に自動で届くメッセージです。

### 設定のしかた

1. ホーム → ステップ配信 → 作成
2. 開始の条件を「友だち追加」にする
3. メッセージを3通並べ、それぞれの待ち時間を入れる
   - 1通目：友だち追加から **1日後**
   - 2通目：1通目から **2日後**（＝3日後）
   - 3通目：2通目から **2日後**（＝5日後）
4. 配信する時間帯を決める（私は10:00〜20:00にしました。夜中や早朝に通知が鳴らないように）
5. 保存して「利用中」にする

待ち時間は「前のメッセージから何日後か」で入れる画面だったので、1日→2日→2日になっています。ここは画面の表示を見ながら合わせてください。

### あいさつと同じ内容は送らない

最初に考えた設計では、友だち追加した直後にも「0通目」を送る予定でした。
でも、あいさつメッセージで無料プレゼントを渡しているので、内容がかぶります。
なので、0通目はやめて、1日後から始めました。

### 事実と合わない言い切りは直す

もう一つ、設計段階の文面から直したところがあります。

最初の下書きには「つまずく人の9割は」「私が毎日使っている」「10分で下書きまで」のような言い切りが入っていました。
数字の根拠がないものや、実際と違うものは、配信する前に全部直しました。

自動で何度も届くメッセージほど、盛った表現がそのまま積み重なります。
設定する前に、1通ずつ「これは本当か」を確認するのがおすすめです。

### テンプレート：1日後（考え方）

```
【読者がつまずきやすいこと】の多くは、"【原因】"でつまずいています。

正しい順番はこれ👇
①【最初にやること】→ ②【次にやること】→ ③【最後にやること】

②③から始めると、「【よくある止まり方】」で止まります。
無料プレゼントの「【該当する部分】」は、①を終わらせるための道具です。

まだ試していなければ、今日1回だけどうぞ。
やってみたら、スタンプ1つ送ってもらえると嬉しいです😊
```

最後の「スタンプ1つ」は、返事のハードルを下げるための一言です。

### テンプレート：3日後（誤解をほどく）

```
「【読者がよく持っている思い込み】」

これは、いちばん多い誤解です。
【思い込みのとおりになる理由】。でも【こうすれば違う結果になる】。

コツは1つ。
【具体的なコツ】。
「【よくある悪い例】」をやめるだけで別物になります。

次は「【次回の予告】」を送りますね。
```

### テンプレート：5日後（自分の商品・ツールの案内）

```
【読者の悩み】のは、意志ではなく"仕組み"がないだけです。

続いている人がやっていること👇
・【やっていること1】
・【やっていること2】
・【やっていること3】

ただ、【手間がかかる部分】を毎回手でやるのは大変です。
そこで作ったのが「【商品・ツール名】」です。

【何をしてくれるか：一文か二文で】

▶ 無料で試す：【URL】
（無料：【無料でできる範囲を正直に】）

「自分に合うか不安」という方は、
このLINEに「聞きたい」と送ってください。個別にお答えします😊
```

案内は5日後の1通だけにして、それまでは役に立つ話だけにしました。

## 9. 散らかった応答メッセージを整理する

新しく作るのと同じくらい大事だったのが、古い設定の片づけです。

見直す前の私のLINEには、こんな状態の応答メッセージがありました。

- 一律応答が3つある（そのうち2つは停止中で、中身も重複）
- 前に使っていた外部ツールへのリンクを返すキーワード応答が残っている
- 今は配っていないプレゼントを配るキーワード応答が残っている
- ツールの使い方の説明が、実際のツールの動きと違う（有料の機能を、誰でも使えるように書いていた）

### 整理した手順

1. 応答メッセージの一覧を開いて、全部の中身を1つずつ読む
2. 「今も配っている？」「今のツールの動きと合っている？」「重複していない？」で仕分ける
3. 重複や、使っていないものは削除
4. 説明が実際と違うものは、実際にツールを触って確かめてから書き直す
5. 最後に、一律応答が「利用中」で1つだけになっているか確認する

私の場合、最終的に応答メッセージは6つだけになりました。

- 特典（キーワード応答）
- 総合（一律応答）
- やり直したい（キーワード応答）
- noteについて（キーワード応答）
- 使い方がわからない系（キーワード応答）
- ツールが開けない系（キーワード応答）

### 消す前に確認すること

キーワード応答を消すと、そのキーワードを送った人には一律応答が返るようになります。

過去の投稿や note で「◯◯と送ってください」と案内していた場合、その言葉を消すと、案内どおりに送った人が期待と違う返事を受け取ります。
消す前に、そのキーワードをどこかで案内していないかを思い出しておくと安心です。

### テンプレート：サポート用キーワード応答（使い方）

```
【サービス名】の基本の流れです👇

STEP1：【最初に押すボタン・やること】
STEP2：【次にやること（目安の時間）】
STEP3：【何が表示されるか】
STEP4：【最後にやること】

無料では、【無料でできる範囲】まで使えます。
【有料の機能】は有料プランです。

どこで止まっているか教えていただければ、詳しくご案内します！
```

ここでも、**実際の画面にあるボタンの名前をそのまま書く**のがポイントです。
私は、説明に書いたボタンがツールに本当にあるかを確認してから入れ直しました。

## 10. 無料プランで気をつけること：メッセージ通数

LINE公式アカウントの無料プランには、1か月に送れるメッセージの通数に上限があります。

ここで押さえておきたいのは、**何が通数に数えられて、何が数えられないか**です。

- あいさつメッセージ：数えられない
- 応答メッセージ（キーワード応答・一律応答）：数えられない
- ステップ配信：**数えられる**

つまり、「特典」と送ってもらって返す分は、何人に送っても通数を使いません。
一方で、ステップ配信は友だち1人につき1通ずつ数えられるので、友だちが増えるほど通数を使います。

この導線だと、友だち1人あたりステップ配信が3通です。
月の上限をどのくらいの人数で超えるかは、プランと、ほかに一斉配信をするかどうかで変わります。

上限の具体的な数字や、プランの内容は変わることがあるので、この記事では書きません。
**管理画面で、今のプランの月間上限と、今月どれだけ使ったかを確認してください。**

友だちが増えてきて上限が近づいたら、そのときにプランを見直せば十分です。私はまだ友だち0人から始めたので、無料プランのままにしています。

## 11. 最後に、自分のスマホで確かめる

設定が終わったら、必ず自分のスマホで試します。

私が確認したのは、この3つです。

- リッチメニューが表示されるか
- 「特典」と送って、プレゼントが自動で届くか
- あいさつメッセージが届くか

あいさつメッセージは友だち追加のときにしか届かないので、一度ブロックして、ブロックを解除して確かめる方法があります。

余裕があれば、ここも試しておくと安心です。

- リッチメニューのボタンを全部押して、それぞれ正しい案内が返るか
- キーワードではない普通の文章を送って、一律応答が返るか
- 応答時間内の時間帯に「特典」と送って、ちゃんと返るか

## 12. 1日でやる順番のまとめ

最後に、やる順番だけまとめておきます。

1. 今ある応答メッセージを全部読んで、重複・古いもの・実際と違うものを片づける
2. キーワード応答「特典」を作る（ゆれそうな言い方もキーワードに足す）
3. サポート用のキーワード応答を、実際の画面に合わせて書き直す
4. 一律応答を1つにして、「人が返事をします」と伝える
5. あいさつメッセージを吹き出し3つで作る（送ることばをカギかっこで見せる）
6. 応答設定で、応答時間内も応答メッセージが出るようにする
7. リッチメニューを作る（テキストはキーワードとぴったり同じに）
8. ステップ配信を1日後・3日後・5日後で作る（言い切りを見直してから）
9. 自分のスマホで全部試す
10. 管理画面で、メッセージ通数の上限を確認する

## おわりに

LINE公式の導線は、外部ツールがなくても、標準の機能だけでここまで組めます。

大事だったのは、
- キーワードは完全一致なので、送る言葉をこちらから渡すこと
- 応答時間の設定で、自動応答が止まっていないか確かめること
- 書いてあることが、本当のことか確かめること

の3つでした。

私の導線は、まだ友だち0人のところから始まったばかりです。
まずは、あなたのLINEで「特典」のキーワード応答を1つだけ作って、自分のスマホから送ってみてください。
