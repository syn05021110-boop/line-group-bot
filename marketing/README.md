# 「副業ドラフト」販売マーケ素材一式

アプリ（https://note-threadssf.onrender.com ）を広めて有料プランにつなげるための、
note記事・SNS投稿の**下書き集**と**運用計画**。

> ⚠️ 投稿（公開）は各自で行う。自動投稿はしない（各SNSの規約・凍結リスクのため）。

## 何を売るか（ぶれない軸）
- **商品**: 副業ドラフト＝AIが自己ヒヤリングであなたの強みを言語化し、Threads/X/Instagram/TikTok/noteの下書き＋プロフィール＋週間カレンダーを自動生成するアプリ
- **ターゲット**: 「副業したいけど、自分に何ができるか・何を発信すればいいか分からない会社員」
- **刺さる一言**: 「発信するネタがない人ほど、実は"売れる強み"を持っている」
- **導線**: note/SNSで価値提供 → プロフィール/公式LINE → アプリ（月5,000円〜）

## ⚠️ 投稿スケジュール（重要・スパム回避）
「今日中に一気に全部出す」はNG。**素材は今日そろえ、公開は分散**する。

| 媒体 | 用意する本数 | 安全な投稿ペース | 出し切る目安 |
|---|---|---|---|
| note | 20本（全て無料） | 1日2〜3本 | 約1週間 |
| Threads | 50投稿 | 1日3〜5投稿（時間を分散） | 約2週間 |
| X | 50投稿 | 1日3〜5投稿 | 約2週間 |
| Instagram | 50投稿 | 1日1〜2投稿 | 約1か月 |

- 新しいアカウントほど、初日から大量投稿すると凍結・シャドウバンの危険。
- 反応（いいね/保存/コメント）が付いた投稿の"型"を見つけ、そこに寄せていくのが伸ばし方。
- どの投稿も最後は「プロフィールのリンク or 公式LINE」へ静かに誘導する。

## フォルダ構成
```
marketing/
├── README.md            ← このファイル（戦略・スケジュール）
├── note-plan.md         ← note20本のタイトル・切り口・狙い（全体設計）
├── notes/               ← note本文の下書き（note-01.md 〜）
├── social-threads.md    ← Threads 投稿下書き（50本を分割で追加）
├── social-x.md          ← X 投稿下書き
└── social-instagram.md  ← Instagram 投稿下書き
```
