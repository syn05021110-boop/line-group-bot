# 手売りDMスクリプト（最初の売上を作る）

最初の数件は、ファネルではなく「1対1の会話」から生まれる。
温かい人（リプをくれた人・濃いフォロワー・LINE登録者）に、売り込まず価値から入る。

## 大原則
- **いきなり売らない**。まず相手の悩みを聞く → 役に立つ → 自然に案内
- 1日数件まで（コピペ連投はスパム・逆効果）
- 相手ごとに1箇所は必ず変える

---

## STEP 1：きっかけ（リプ/コメントをくれた人へ）
```
コメントありがとうございます！
○○（相手の発言）、すごく分かります。
ちなみに今、発信で一番つまずいてるのってどこですか？
```
→ まず会話を始める。売らない。

## STEP 2：価値提供（相手が悩みを話したら）
```
なるほど、○○で止まってるんですね。
それ、△△（具体的な一言アドバイス）から試すとラクになりますよ。
もしよければ、無料で配ってるプロンプト集が役に立つかも → （LINE or noteのURL）
```
→ 無料で役に立つ。ここで信頼ができる。

## STEP 3：自然な案内（相手が前向きなら）
```
もし「一人だと続かない」「一緒に伴走してほしい」みたいな感じなら、
3名限定で90日の個別サポートもやってます。
合うか確認するだけの無料面談もできるので、気になったら「伴走希望」って送ってください😊
```
→ 押さない。「気になったら」で相手に委ねる。

---

## 入口（¥980）をすすめる場合
```
発信ネタで困ってるなら、用途別のプロンプト50個をまとめたnoteがちょうど合うかも。
コピペで使えるやつです → （note URL）
```

## やってはいけない
- 初手で商品リンクを送る（ブロックされる）
- 同じ文のコピペ連投（スパム判定）
- 「稼げます」と断定する（信頼を失う＆規約リスク）

## メンタル
- 断られて当然。3人に案内して1人面談できれば上出来
- 最初の1件が出れば、"お客様の声"が次を連れてくる
