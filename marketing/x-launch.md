# X（旧Twitter）展開一式

原則：Threadsの投稿を転用しつつ、Xは「短く・断定・1ツイート1メッセージ」。日本語は約140字が目安。

## プロフィール
- **名前**：Mao｜AIで会社員の副業を仕組み化
- **bio**：
```
会社員×AIで副業を仕組み化｜難しいプロンプト不要で 強みの言語化→発信→収益化を時短｜元○○｜🎁AI発信スターターキット無料配布中→https://lin.ee/RzyA13P
```
- **固定ツイート**：下の「固定用」を投稿してピン留め。

## 固定用ツイート
```
会社員がAIで副業を始めるなら、順番はこれだけ。

①棚卸し（強みを言葉に）
②発信（仕組み化）
③収益化

②③から始めるから挫折する。
このアカウントで、①からの具体的なやり方を毎日発信します。

🎁無料キットはプロフのリンクから
```

## X最適化ポスト15本（≤140字目安）

1. 会社員の9割、AIを"検索"にしか使ってない。もったいない。最強の使い方は「自分の強みを言葉にさせる」こと。あなたは何に使ってる？

2. 「AIで副業」は難しいプロンプト不要。自分の経験を渡して"質問させる"だけで、発信ネタが無限に出る。丸投げが没個性なだけ。

3. 副業で消耗する人の共通点：毎回ゼロから考えてる。続く人はAIで作りだめ。しんどさは根性じゃなく仕組みで消える。

4. AIに「いい感じにして」は禁止。9割が損してる。「誰に・何を・どんなトーンで・何字で」を渡すだけで出力が別物になる。

5. 発信が続かないのは意志が弱いからじゃない。仕組みが無いだけ。週末30分、AIで作りだめ→平日は出すだけ。これで続く。

6. 「自分には何もない」は9割が言語化してないだけ。AIに"最近ありがとうと言われたこと"を話すと、強みが勝手に見えてくる。

7. 副業の第一歩は商品作りじゃない。「強みの言語化」。順番はいつも 言語化→発信→収益化。逆走してる人が多すぎる。

8. 「元○○」は最強の肩書き。前職の当たり前は、外では専門知識。AIに整理させれば立派なコンテンツになる。あなたの前職は？

9. noteが書けないのは文章力のせいじゃない。"白紙"だから。AIに構成だけ作らせると、埋めるだけで9割終わる。

10. フォロワー1万の"なんとなく"より、濃い10人。数を追うほど遠回り。届ける相手は1人でいい。

11. AIに丸投げした投稿は伸びない。あなたの体験が抜けるから。一般論はAIが量産できる。でも失敗も口ぐせもコピーできない。

12. 会社員こそAIが効く。時間がないを言い訳にできなくなる。スキマ5分で下書き1本。むしろ今が始めどき。

13. ネタが尽きる人は頭の中で探す。尽きない人はAIで"1テーマを10の切り口に分解"。1ネタが10投稿に化ける。

14. プロフィールの1行、9割が損してる。「日々発信中」じゃ何者か伝わらない。「肩書き＋誰の役に立つか」に変えるだけでフォロー率が変わる。

15. いちばん若い今日から。強みを1つ言葉にして1投稿。AIが手伝ってくれる。それだけで自分メディアが動き出す。
