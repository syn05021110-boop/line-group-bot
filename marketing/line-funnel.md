# LINE公式 動線設計（Threads → LINE → 教育 → 商品）

> **管理画面に貼る完成版は `line-setup.md`**（2026-09-28）。このファイルは考え方と経緯。UTAGE 等の外部ツールは使わない。

伸びてるAIアカの定石：**Threadsで集客 → LINE公式で無料プレゼント配布 → 数通で教育 → 商品案内**。
冷たい客をLINEで温めてから売るので、Stripe直販より圧倒的に売れる。

## 全体像
```
Threads/固定投稿 →「無料プレゼント🎁」→ LINE公式に登録
   ↓ あいさつメッセージ（登録直後・自動）
   キット配布 ＋ 期待値づくり
   ↓ ステップ配信（0日/1日/3日/5日）
   教育 → 信頼 → 本命（AIツール）案内
```

## 設定方法（コード不要）
LINE Official Account Manager で設定：
- **あいさつメッセージ**（無料・登録直後に自動送信）… 下の「0通目」
- **ステップ配信**（登録起点で自動ドリップ）… 1〜4通目
  ※ プランでステップ配信が使えない場合は、当面「一斉配信」で手動でもOK。

## 補足（伸ばすコツ）
- 商品案内は"5通目まで我慢"。先に価値と信頼を渡すほど売れる。
- 各通で「スタンプ1つ返してね」等の**軽い反応導線**を入れると、以降の到達率が上がる。
- 個別相談（1:1）に持ち込めた人は成約率が段違い。最初の数件は手売りで実績＆声を集める。

## 実際の設定と設計のズレ（2026-09-28 確認）

LINE Official Account Manager を確認した時点の実設定は、上の設計と違い **ツールのサポート窓口** になっている。

- あいさつメッセージ：「SNS投稿AI設計ツールのサポートLINEへようこそ」。無料プレゼントの案内がない
- 応答メッセージ（一律応答）「総合」：24時間以内に返信する旨
- 応答メッセージ（キーワード応答）：
  - 「やり直したい」…修正／やり直し／訂正／もう一度／変えたい／もう一回
  - 「noteについて」…note／下書き／記事
  - 「使い方がわからない系」…使い方／やり方／操作／どうすれば
  - 「ツールが開けない系」…開けない／URL／リンク／アクセス／ページ

### 問題点
1. スターターキット note に「追加特典は公式LINEで」と書くのに、LINE 側に特典の受け取り口がない
2. キーワード応答は **完全一致** のみ。「ツールが開けないです」では反応せず、一律応答になる
3. 「使い方」「note」の応答にある「5つ答えると1週間分が完成」「1週間分のあとに note 下書きを提案」は、有料機能（1週間カレンダー・note下書き）の説明。無料ユーザーには出ないので問い合わせの元になる。**実際の動きを確認して直す**
4. 名前が「SNS投稿AI設計ツール」と「副業ドラフト」で揺れている
