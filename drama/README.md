## 1. 大前提：この規模で「アニメ」をどう作るか

フルアニメーション（毎秒12〜24枚作画）は個人規模では破綻する。
縦型ショートで実際に回っている作り方は次の3つで、**本シリーズは B を基本線**とする。

| 方式 | 中身 | 1本の制作時間 | 向き |
|---|---|---|---|
| A. 静止画紙芝居 | 生成した1枚絵＋寄り引き（Ken Burns）＋テロップ | 2〜3時間 | 最速。動きの説得力は低い |
| **B. i2v ハイブリッド（採用）** | 1枚絵を生成 → 動画AIで2〜5秒だけ動かす → 繋ぐ | **4〜6時間** | 品質と工数のバランスが最良 |
| C. Live2D / パペット | キャラを部位分割して動かす | 10時間〜 | 継続キャラを長期運用するなら |

B の要点は「**全カットを動かさない**」こと。
14カット中、実際に動画化するのは **表情が動く4〜5カットだけ**。残りはカメラワークとエフェクトで持たせる。視聴者は 55 秒で判断するので、動いていないカットは気づかれない。

## 2. 制作フロー（1本あたり）

```
① 脚本確定              30分   ← series-plan.md からネタを選び、55秒に圧縮
② キャラシート生成       初回のみ  ← 一度作れば全話で使い回す（後述）
③ カット絵の生成        90分   ← 14カット。1カットあたり3〜5回リテイク前提
④ 動く4〜5カットを i2v   60分   ← 生成待ち時間が長いので③と並行させる
⑤ 音声（セリフ）        30分   ← 読み上げAI。または自分の声＋加工
⑥ 編集・SE・テロップ    90分   ← ここが一番効く。手を抜かない
⑦ 書き出し・投稿        30分
                      ─────
                      約5時間／本
```

**週2本（火・金 21:00 投稿）が現実的な巡航速度。** 最初の1ヶ月は週1本でも構わないが、投稿を止めないことを最優先にする。

## 3. ツール選定

| 工程 | 第一候補 | 代替 | 備考 |
|---|---|---|---|
| 静止画生成 | Nano Banana（Gemini画像生成） | Midjourney / SDXL+LoRA | **キャラ一貫性が最重要**。参照画像を渡せるモデルを選ぶ |
| 画像→動画 | Kling | Hailuo / Runway / Sora | 1カット5秒。日本語アニメ調の相性で選ぶ |
| セリフ音声 | ElevenLabs（日本語） | にじボイス / VOICEVOX | キャラごとに声を固定する |
| 編集 | CapCut（縦型テンプレが速い） | Premiere Pro / DaVinci | 縦型9:16・1080×1920 |
| 効果音 | 効果音ラボ（無料・商用可） | Epidemic Sound | 心音・ノイズ・ブツ切り音は必須 |
| BGM | Epidemic Sound / Artlist | DOVA-SYNDROME | **必ず商用ライセンスを確認する** |

> 各サービスの最新バージョン・料金・利用規約は変動するため、契約前に必ず公式で確認すること。特に「生成物の商用利用可否」と「収益化プラットフォームへの投稿可否」は要確認。

**月額の目安：画像生成 + 動画生成 + 音声 + BGM で 8,000〜15,000円程度。** 最初は無料枠・低額プランで1話作りきってから増やす。

## 4. キャラクター一貫性の作り方（最重要）

AIアニメが素人臭くなる原因の9割は「**カットごとに顔が違う**」こと。ここだけは仕組みで解決する。

> 具体的なプロンプトと手順は **`ep01/character-sheet.md`** にまとめてある。実制作ではそちらを使う。

### 手順
1. **マスター1枚（正面・バストアップ・無表情）を全力で作る。** 三面図と表情を1枚に同時生成すると枠ごとに顔がバラつくため、マスターを確定させてから角度・表情を1枚ずつ派生させる。
2. その画像を保存し、**以降の全カット生成でリファレンス画像として毎回添付する。**
3. プロンプトに固定文言（後述の「スタイル固定ブロック」）を毎回コピペする。
4. seed を固定できるモデルなら固定する。
5. それでもズレたカットは**採用しない**。リテイクするか、そのカットを「後ろ姿」「手元アップ」「顔が影で見えない」構図に逃がす。

> **逃げ構図は敗北ではなく演出。** サスペンスは顔を見せない方が怖い。一貫性の弱点をジャンルの武器に転換できる。

### スタイル固定ブロック（全カット共通・毎回コピペ）

```
Japanese late-night anime style, cel shading, clean lineart, muted desaturated
palette, deep blue night tones with a single warm light source, cinematic
composition, film grain, vertical 9:16 aspect ratio, no text, no watermark
```

## 5. 品質基準（投稿前チェックリスト）

- [ ] **0〜3秒で状況と不穏さが伝わるか。** ここで離脱されたら他は無意味
- [ ] 音を消しても意味が通るか（テロップは全セリフに焼く。無音視聴が半数）
- [ ] キャラの顔が全カットで同一人物に見えるか
- [ ] ラスト5秒に反転があるか
- [ ] **2回目を見たときに気づく伏線が、1カット目に置かれているか**
- [ ] 尺は45〜60秒に収まっているか
- [ ] テロップが下部30%（UIに隠れる領域）にかかっていないか
- [ ] 書き出し：1080×1920 / 30fps / H.264 / 音量ピーク −3dB

## 6. 権利・表示まわりの注意

- BGM・効果音は**商用利用可のライセンス**のものだけを使う。プラットフォームの著作権検知は自動で走る
- 実在の人物・企業・団体を想起させる名称は使わない
- 実在の事件を題材にしない
- 生成AIの利用表示について、各プラットフォームの最新ポリシーに従う（YouTube は合成コンテンツの開示設定がある）
- 恐怖表現は「**血・遺体・自傷を映さない**」を自主基準とする。年齢制限がつくと露出が落ちるため、実利としても正しい
