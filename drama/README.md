# 縦型アニメ短編ドラマ 制作ドキュメント

Instagram リール / YouTube ショート向けの、**アニメ表現によるどんでん返しサスペンス短編**シリーズの制作資料。

| ファイル | 内容 |
|---|---|
| `README.md`（このファイル） | 制作フロー・ツール・原価・品質基準 |
| `series-plan.md` | シリーズ企画『ラスト5秒』とエピソード案10本 |
| `ep01/character-sheet.md` | キャラ・美術の基準素材を作る手順とプロンプト（**本編カットより先にやる**） |
| `ep01/script.md` | 第1話「白い服」完全脚本＋カット表＋生成プロンプト＋投稿文 |

---

## 1. 大前提：この規模で「アニメ」をどう作るか

フルアニメーション（毎秒12〜24枚作画）は個人規模では破綻する。
縦型ショートで実際に回っている作り方は次の3つで、**本シリーズは B を基本線**とする。

| 方式 | 中身 | 1本の制作時間 | 向き |
|---|---|---|---|
| A. 静止画紙芝居 | 生成した1枚絵＋寄り引き（Ken Burns）＋テロップ | 2〜3時間 | 最速。動きの説得力は低い |
| **B. i2v ハイブリッド（採用）** | 1枚絵を生成 → 動画AIで2〜5秒だけ動かす → 繋ぐ | **4〜6時間** | 品質と工数のバランスが最良 |
| C. Live2D / パペット | キャラを部位分割して動かす | 10時間〜 | 継続キャラを長期運用するなら |

B の要点は「**全カットを動かさない**」こと。
14カット中、実際に動画化するのは **表情が動く4〜5カットだけ**。残りはカメラワークとエフェクトで持たせる。視聴者は 55 秒で判断するので、動いていないカットは気づかれない。

## 2. 制作フロー（1本あたり）

```
① 脚本確定              30分   ← series-plan.md からネタを選び、55秒に圧縮
② キャラシート生成       初回のみ  ← 一度作れば全話で使い回す（後述）
③ カット絵の生成        90分   ← 14カット。1カットあたり3〜5回リテイク前提
④ 動く4〜5カットを i2v   60分   ← 生成待ち時間が長いので③と並行させる
⑤ 音声（セリフ）        30分   ← 読み上げAI。または自分の声＋加工
⑥ 編集・SE・テロップ    90分   ← ここが一番効く。手を抜かない
⑦ 書き出し・投稿        30分
                      ─────
                      約5時間／本
```

**週2本（火・金 21:00 投稿）が現実的な巡航速度。** 最初の1ヶ月は週1本でも構わないが、投稿を止めないことを最優先にする。

## 3. ツール選定

| 工程 | 第一候補 | 代替 | 備考 |
|---|---|---|---|
| 静止画生成 | Gemini の画像生成（Nano Banana） | niji・journey / NovelAI | **↓ 下の節で詳述** |
| 画像→動画 | Kling | Hailuo / Runway / Sora | 1カット5秒。日本語アニメ調の相性で選ぶ |
| セリフ音声 | ElevenLabs（日本語） | にじボイス / VOICEVOX | キャラごとに声を固定する |
| 編集 | CapCut（縦型テンプレが速い） | Premiere Pro / DaVinci | 縦型9:16・1080×1920 |
| 効果音 | 効果音ラボ（無料・商用可） | Epidemic Sound | 心音・ノイズ・ブツ切り音は必須 |
| BGM | Epidemic Sound / Artlist | DOVA-SYNDROME | **必ず商用ライセンスを確認する** |

> 各サービスの最新バージョン・料金・利用規約は変動するため、契約前に必ず公式で確認すること。特に「生成物の商用利用可否」と「収益化プラットフォームへの投稿可否」は要確認。

**月額の目安：画像生成 + 動画生成 + 音声 + BGM で 8,000〜15,000円程度。** 最初は無料枠・低額プランで1話作りきってから増やす。

### 3-1. 静止画生成サービスの選び方

選定基準は**ひとつだけ**。**「マスター画像を参照として渡し、同じ顔で別の表情・別の角度を出せるか」**。
絵の綺麗さは二の次。綺麗でも顔が毎回変わるサービスは、このシリーズでは使えない。

| サービス | 一貫性の担保方法 | 日本語 | 月額目安 | 向き／不向き |
|---|---|---|---|---|
| **Gemini の画像生成（Nano Banana）** ★本命 | 参照画像を添付して「同じキャラで」と指示 | ◎ そのまま通る | 無料枠あり／有料 約3,000円〜 | **参照追従とチャットでの微修正が最も素直。まずここで1話作りきる** |
| **niji・journey**（Midjourney のアニメ特化モデル） | `--cref`（キャラ参照）／`--sref`（画風参照） | △ 英語推奨 | 約1,500円〜 | 絵の質は最上位。**質を上げたくなった段階で移行する**。学習コストはやや高い |
| **NovelAI** | Vibe Transfer | ○ | 約1,500〜4,000円 | 日本の深夜アニメ絵に最も近い画風。**画風を最優先するなら** |
| ローカル SD + LoRA | LoRA を自分で学習 | ○ | GPU代のみ | 一貫性は最強だが、**GPUと数日の学習コストが必要。最初にやることではない** |

**推奨ルート：Gemini の無料枠で第1話を最後まで作る → 続けられそうなら有料化 → 絵の質に不満が出たら niji・journey を試す。**
最初から複数を比較検討して時間を溶かすのが一番よくない。1話完成させることを最優先にする。

> **料金・機能・モデル名は変動が激しい。** 上表は目安であり、契約前に必ず公式で最新情報を確認すること。

### 3-2. 商用利用の確認（課金前に必ず）

生成物を収益化チャンネルに投稿する以上、次の3点は**自分の目で規約を確認する**こと。

1. **生成物を商用利用してよいか**（無料プランは商用不可のサービスがある。**有料プラン推奨**）
2. **YouTube / Instagram への投稿と収益化が許可されているか**
3. **生成物が他ユーザーに公開される設定になっていないか**（Midjourney 系は既定で公開ギャラリーに載る）

### 3-3. 生成の自動化（`drama/tools/generate.mjs`）

Web の画面から1枚ずつ作ってもよいが、**参照画像の添付忘れ**と**ファイル名の付け間違い**が
一貫性を壊す二大要因なので、スクリプトから叩いたほうが事故が減る。

```bash
export GEMINI_API_KEY=...                        # Google AI Studio で発行

node drama/tools/generate.mjs --list             # 対象と依存関係の一覧
node drama/tools/generate.mjs akari_master --n 4 # マスターを4案出す
node drama/tools/generate.mjs akari_freeze       # 参照画像は自動で添付される
node drama/tools/generate.mjs --all              # 依存順に20点まとめて
```

プロンプトの実体は **`drama/prompts.json`**。`character-sheet.md` と同じ文言が入っているので、
**直すときは両方直す**こと。

#### 運用ルール

- 出力は `drama/ep01/assets/<dir>/<name>_v<N>.png`。**既存ファイルは絶対に上書きしない**
- 気に入った1枚を **`<name>.png` にリネームする**。これが「確定版」で、以降の参照元になる
- 確定版が無い状態で派生を作ろうとすると、**エラーで止まる**（API を呼ぶ前に止まるので課金されない）
- git には**確定版だけ**が入る。`_vN` と本編カットは `.gitignore` 済み

#### つまずいたら

| 症状 | 対処 |
|---|---|
| モデルIDのエラー | `GEMINI_IMAGE_MODEL` env で差し替える。提供モデル名は変わるので公式ドキュメントを確認 |
| `finishReason` 付きで画像が返らない | 安全フィルタ。恐怖表現の語を弱める（`ominous` → `quiet` など） |
| レート制限 | 1.5秒間隔を入れてあるが、無料枠では `--n` を小さくする |

### 3-4. 動画にする（`drama/tools/animatic.mjs` / `video.mjs`）

編集タイムラインは **`drama/timeline.json`**。`script.md` のカット表と1対1で対応している。

#### 手順

**① まず静止画だけで通しを書き出す。**

```bash
node drama/tools/animatic.mjs --dry-run    # 実行せずffmpegコマンドを確認
node drama/tools/animatic.mjs              # ep01/out/animatic.mp4
node drama/tools/animatic.mjs --cut C12    # 1カットだけ確認
```

寄り引き（Ken Burns）とテロップ焼き込みまで入った 1080×1920 / 30fps の mp4 が出る。
**i2v を1本も作っていなくても通しが出る**ので、ここで尺とテンポを固めてしまう。
この段階で「間延びしている」「フックが弱い」が分かる。**絵を作り込む前に気づけるのが最大の利点。**

**② テンポが決まってから、動かす5カットだけ i2v にかける。**

```bash
node drama/tools/video.mjs --list          # 対象と生成済みかどうか
node drama/tools/video.mjs C13             # 1本だけ
node drama/tools/video.mjs --all           # 5本まとめて（数十分かかる）
```

出力は `assets/clips/<id>.mp4`。**animatic.mjs が次回から自動で拾う**ので、
もう一度 `animatic.mjs` を叩けば差し替わった通しが出る。

**③ 音を足す。**

```bash
node drama/tools/animatic.mjs --audio ep01/assets/audio/mix.wav
```

セリフ・BGM・SE のミックスは編集ソフト側で作り、1本の wav にして渡す。

#### 必要なもの

```bash
# macOS
brew install ffmpeg
# Ubuntu
sudo apt install ffmpeg fonts-noto-cjk
```

**日本語フォントが無いとテロップが豆腐になる。** 見つからない場合は
`TELOP_FONT=/path/to/font.ttc` で明示する。

#### つまずいたら

| 症状 | 対処 |
|---|---|
| テロップが □□□ になる | フォント未検出。`TELOP_FONT` を指定する |
| ズームがガタつく | 元画像の解像度が低い。生成時に大きめに出す |
| 結合時にエラー | 全カットの解像度・fps が揃っていない。`--cut` で個別に確認する |
| Veo のモデルIDでエラー | `GEMINI_VIDEO_MODEL` で差し替える。提供モデルは変動する |
| i2v で顔が別人になる | そのカットは静止画のまま使う。**動かないカットは誰も気づかない** |

## 4. キャラクター一貫性の作り方（最重要）

AIアニメが素人臭くなる原因の9割は「**カットごとに顔が違う**」こと。ここだけは仕組みで解決する。

> 具体的なプロンプトと手順は **`ep01/character-sheet.md`** にまとめてある。実制作ではそちらを使う。

### 手順
1. **マスター1枚（正面・バストアップ・無表情）を全力で作る。** 三面図と表情を1枚に同時生成すると枠ごとに顔がバラつくため、マスターを確定させてから角度・表情を1枚ずつ派生させる。
2. その画像を保存し、**以降の全カット生成でリファレンス画像として毎回添付する。**
3. プロンプトに固定文言（後述の「スタイル固定ブロック」）を毎回コピペする。
4. seed を固定できるモデルなら固定する。
5. それでもズレたカットは**採用しない**。リテイクするか、そのカットを「後ろ姿」「手元アップ」「顔が影で見えない」構図に逃がす。

> **逃げ構図は敗北ではなく演出。** サスペンスは顔を見せない方が怖い。一貫性の弱点をジャンルの武器に転換できる。

### スタイル固定ブロック（全カット共通・毎回コピペ）

```
Japanese late-night anime style, cel shading, clean lineart, muted desaturated
palette, deep blue night tones with a single warm light source, cinematic
composition, film grain, vertical 9:16 aspect ratio, no text, no watermark
```

## 5. 品質基準（投稿前チェックリスト）

- [ ] **0〜3秒で状況と不穏さが伝わるか。** ここで離脱されたら他は無意味
- [ ] 音を消しても意味が通るか（テロップは全セリフに焼く。無音視聴が半数）
- [ ] キャラの顔が全カットで同一人物に見えるか
- [ ] ラスト5秒に反転があるか
- [ ] **2回目を見たときに気づく伏線が、1カット目に置かれているか**
- [ ] 尺は45〜60秒に収まっているか
- [ ] テロップが下部30%（UIに隠れる領域）にかかっていないか
- [ ] 書き出し：1080×1920 / 30fps / H.264 / 音量ピーク −3dB

## 6. 権利・表示まわりの注意

- BGM・効果音は**商用利用可のライセンス**のものだけを使う。プラットフォームの著作権検知は自動で走る
- 実在の人物・企業・団体を想起させる名称は使わない
- 実在の事件を題材にしない
- 生成AIの利用表示について、各プラットフォームの最新ポリシーに従う（YouTube は合成コンテンツの開示設定がある）
- 恐怖表現は「**血・遺体・自傷を映さない**」を自主基準とする。年齢制限がつくと露出が落ちるため、実利としても正しい
