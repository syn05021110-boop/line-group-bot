# 『ラスト5秒』第1話「白い服」

- **尺**：55秒（＋ロゴ1秒）
- **カット数**：14
- **登場人物**：2人 ／ **舞台**：2部屋（ほぼ同じ美術を流用可）
- **反転**：白い服の人影がいたのは、主人公の部屋ではなく**通話相手の部屋**だった

---

## 1. あらすじ

引っ越し初日の夜、アカリは友人ミナとビデオ通話をしている。
ミナが「今そっちに誰かいた？」と言う。アカリの部屋には誰もいない。
部屋中を確認して、笑って安心した直後——アカリは、画面の向こう、**ミナの背後**に気づく。

## 2. 伏線（2回目の視聴で気づく箇所）

| どこ | 何を仕込むか |
|---|---|
| **C1** | ミナの背後のドアが**数センチだけ開いている**。暗くて分かりにくいが、確実に映す |
| **C3** | 「画面の奥」と言うとき、ミナの視線が**画面の隅（自分のプレビュー小窓）**に向いている |
| **C6・C7** | アカリ側は**戸締まりが完璧**であることを丁寧に見せる。「アカリ側ではない」の消去法になる |
| 全編 | **アカリもミナも白い服を着ていない。** 白はこの回では人影の専用色 |

> 制作上の最重要ルール：**主要キャラに白を着せない。** ここが崩れると反転が読めなくなる。

---

## 4. 別エンディング案（採用は任意）

黒画面の後にもう1カット足す：**アカリの部屋の玄関チェーンが、外れている。**

- 利点：二段オチでインパクトが増す
- 欠点：「脅威はミナ側」という反転の輪郭がぼやける。**第1話では推奨しない**
- 使いどころ：シリーズ後半、視聴者が型に慣れてきた頃の変化球として

---

## 5. 音響設計

| 要素 | 方針 |
|---|---|
| BGM | 低音のドローン1本のみ。**C4 とC11 で止める。** 音を止めることが最大の恐怖演出 |
| 心音 | C4 に1回、C13 に2回。それ以上入れると安っぽくなる |
| 通話ノイズ | 全編に極小音量で敷く。切断時に消えると体感が変わる |
| セリフ | 読み上げAIは**気持ち控えめの演技**に。過剰な演技は縦型では浮く |
| 音量 | ピーク −3dB。スマホのスピーカーで確認する |
